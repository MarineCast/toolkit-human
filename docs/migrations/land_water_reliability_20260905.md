# Land and water reliability contracts, 2026-09-05

Land releases now declare `land_product_schema_version=4.1.0-research` and `land_semantic_version=source_cell_common_reference_v1`. Old generations remain immutable. Re-run land download before build to pin the exact partition set and semantic manifests. Changed, added, and removed partitions invalidate the inventory; consumption decodes checksum-validated bytes. Geometry cache keys include dataset content and every shapefile member.

The activity budget belongs to a source cell. Eligible local destinations share that budget; within-site samples sum to one. Global parent geometry shares remain descriptive and do not scale that budget. Cache algorithms are `source_cell_local_destinations_v3` and `source_cell_radius_reference_kernel_v3`.

`*_REGIONAL_INVENTORY_SOURCE_FRACTION` names the regional inventory ratio explicitly. Existing `*_STATIC_CONTEXT_FRACTION` columns remain deprecated compatibility aliases with that same regional meaning. They are not target-local confidence, complete access mapping, or reporting capture. `TARGET_LOCAL_VERIFIED_REFERENCE_FRACTION` divides verified pre-weather support by mapped pre-weather support using the same mapped allocation and canonical water-area weights; the numerator is a subset. Its raw numerator, raw denominator, and state remain separate. An unknown activity contribution keeps the local ratio unknown; a nonpositive denominator produces null/not-applicable.

The land reader allowlists legacy schemas 1.0.0, 2.0.0, 3.0.0-research, and the original manifest-schema-v1 envelope for this exact product. Research schemas 4.0 and 4.1 require matching formula identity; 4.1 also requires the semantic version above. Structural publication checks do not grant scientific eligibility. Use `research_adapter="source_cell_reference_v1"` explicitly for 4.1 reads; the older boolean opt-in selects only the v4.0 adapter. Unknown schemas/semantics fail closed. Products remain `model_eligible=false`.

Water publishes `water_semantic_version=fine_distance_water_area_independent_conditions_v1`. Re-run water download to pin canonical DEM/water/land source identities before building. Fine R7 source-target distances are binned before parent aggregation. Targets are averaged using the complete canonical raster water-area inventory, independent of sparse positive pairs. AIS R6 totals retain an explicit uniform allocation over modeled source children; this is not measured fine AIS. Native ferry sources remain separate. The old observer-effort parent kernel remains a deprecated sensitivity interface with its prior meaning.

Each water condition mean uses its own available static support; its `_COVERAGE` column records the denominator fraction. `DYNAMIC_CONDITION_COVERAGE` records joint availability. Composite sums retain available contributions without extrapolation and expose component condition coverage. Known activity/daylight/visibility zeros require no irrelevant weather. Unknown AIS spatial/temporal coverage still prevents complete total-zero claims. No universal water sum is introduced: all-vessel AIS includes classes, and passenger AIS can overlap ferry activity.

Water output dates remain the explicitly labeled fixed historical interval 2020-01-01 through 2024-12-31. Missing source dates remain unavailable. This is not current operational coverage. No regional water regeneration was run in this release.

Lag/rolling kernels query frozen fitted calendar history at prediction time. ISO weeks and day-of-year are supported. `AS_OF` is an exclusive knowledge boundary; a historical period must have ended by it. `REF_YEAR`/`REF_PERIOD` identify the inclusive last known period. Missing periods are not bridged, and later horizons are not filled recursively. Fallback values obey the same bounds and predictions expose the actual fallback source, including bulk calls. All logistic APIs use the serialized fitted feature order and transforms. `use_kernel_logit_feature` names the learned prior covariate; old offset option names remain aliases and do not represent a fixed-coefficient offset.

Artifact-family publication uses exclusive POSIX ownership over the entire recovery parent. Recovery, staging, promotion, and cleanup share that ownership. Corrupt journals and unsuccessful recovery retain evidence. A concurrent writer fails without rolling back the owner.
